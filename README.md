# Где животное

Публичное веб-приложение для просмотра и добавления встреч с животными на интерактивной карте. Регистрация не требуется. Планируется поддержка русского и английского языков.

Проект находится на этапе подготовки архитектуры. Демонстрационный экран Vite удалён; приложение пока отображает пустой экран. Карта и пользовательские сценарии ещё не реализованы.

## Запуск

```sh
npm ci
npm run dev
```

## Проверки и сборка

```sh
npm run lint
npm run build
```

`npm run build` выполняет проверку TypeScript и создаёт production-сборку в `dist/`.

Для локального просмотра готовой сборки:

```sh
npm run preview
```

Vitest, React Testing Library и Playwright установлены. Настройка тестов и команды их запуска пока не добавлены.

## Стек

React, TypeScript, Vite, MapLibre GL JS, TanStack Query, React Hook Form, Zod, i18next и react-i18next. Для стилей используются CSS Modules и CSS Custom Properties.

## Структура

```text
src/
├── main.tsx   # Точка входа
├── app/       # Инициализация приложения, providers, глобальные стили
├── pages/     # Самостоятельные страницы
├── widgets/   # Крупные блоки интерфейса
├── features/  # Пользовательские действия
├── entities/  # Доменные сущности
└── shared/    # Общий API-клиент, UI-примитивы и utilities
```

Папки для будущих модулей подготовлены; большинство из них пока пустые. Папка `e2e/` предназначена для сквозных тестов.

Основная страница — карта. Её сценарии открываются в overlay без размонтирования карты. Архитектура допускает добавление других самостоятельных страниц.
