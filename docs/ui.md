# Интерфейс

## Компоненты

shared/ui содержит чистые переиспользуемые примитивы: Button, Input, Textarea, Chip, Badge, Dialog, Icon.

Использовать props, variants и composition вместо отдельного primitive для каждого варианта. Button поддерживает текст, ведущую/завершающую иконку и режим только с иконкой; Input при необходимости — ведущую иконку и завершающий элемент.

Не создавать без необходимости IconButton, SearchInput, LocationInput, PeriodButton. AnimalSelector, ObservationCard, VotingControl и MapFilterPanel относятся к продуктовым слоям.

Выделять компонент, когда он переиспользуется, имеет собственное поведение или чёткую UI-ответственность либо существенно улучшает читаемость. Не дробить JSX ради количества строк. Обобщать реальные повторяющиеся паттерны.

## Стили

- Локальные стили — CSS Modules рядом с компонентом.
- Общие design tokens — CSS Custom Properties: цвета, интервалы, радиусы, тени и другие повторяющиеся значения.
- Не дублировать общие tokens в компонентах.
- Глобальные стили минимальны.
- Не использовать inline styles для статических стилей; они допустимы для действительно динамических значений, если class или CSS Custom Property не подходят.
- Не добавлять dark/system theme или переключатель темы без изменения требований продукта.

## Адаптивность и доступность

На странице карты карта остаётся основой интерфейса на всех размерах экрана. Другие страницы могут иметь собственную адаптивную композицию.

Desktop/tablet могут использовать popup, dialog, floating/side panel. Mobile — bottom sheet, полноэкранный overlay или другое подходящее представление.

Не дублировать бизнес-логику для desktop и mobile. При необходимости разделять общее поведение и представления.

Сохранять семантику элементов, доступные названия и управление с клавиатуры. В overlay учитывать управление фокусом.

## Локализация и животные

Пользовательские строки хранить в translation resources и получать через t(...), а не размещать по JSX. Переключение языка не перезагружает страницу.

Животное отображается локализованным названием без отдельной иконки. На карте название показывается в текстовом маркере; в селекторах, chips, форме и информации о встрече используется текст.
