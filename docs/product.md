# Продуктовые правила

## Сценарии карты

Пользователь выбирает животных и период, просматривает встречи на карте, открывает конкретную встречу, голосует и добавляет новую встречу.

Выбор животных, просмотр и добавление встречи, голосование и результат публикации выполняются поверх карты. Открытие, закрытие и переключение этих интерфейсов не размонтируют карту и не заменяют её отдельным экраном.

## Животные и фильтры

Животные представлены плоским списком без категорий.

Для запроса встреч обязательны:

- от 1 до 5 выбранных животных;
- один период: последний час, 24 часа, 7 дней или 30 дней.

Если обязательные фильтры не выбраны, запрос встреч не выполнять. Максимум одновременно выбранных животных — 5.

## Добавление встречи

Форма открывается поверх карты.

| Поле           | Обязательность |
| -------------- | -------------- |
| Животное       | Обязательно    |
| Местоположение | Обязательно    |
| Дата           | Обязательно    |
| Время          | Обязательно    |
| Дополнительно  | Необязательно  |

Фотографии не используются.

После валидного submit встреча публикуется сразу. Отдельный review/confirmation step перед публикацией не нужен.

## Голосование

Для опубликованной встречи доступны «Подтверждаю» и «Не подтверждаю».

Пользователь может не иметь голоса, выбрать один из вариантов или изменить свой голос.

Голосование относится только к опубликованной встрече. Не смешивать его состояние с формой публикации.
